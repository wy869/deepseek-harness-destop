1. 产品简介

DeepSeek Harness 桌面版 是一个桌面启动器：双击桌面图标，即可在一个独立的桌面窗口中打开 DeepSeek Harness，无需再打开浏览器，也没有标签页和地址栏，体验如同一个本地安装的桌面应用。

  • 一键启动：双击图标，自动拉起后台服务并弹出应用窗口；已在运行时不会重复启动。
  • 启动动画：点击后显示「DeepSeek Harness」启动动画（DeepSeek 鲸鱼图标 + 进度条），启动完成后自动进入应用。
  • 独立窗口：自动检测系统默认/已安装的浏览器，以「应用模式」打开无标签页、无地址栏的独立窗口，不会新开普通浏览器窗口。
  • 随窗口启停：关闭窗口后自动结束后台 dsh web 进程；下次点击图标自动重新启动。
  • 首次配置：首次使用时弹出输入框要求输入 DeepSeek API Key 并联网校验，通过后保存到本机凭据。
  • 官方图标：桌面/开始菜单图标采用 DeepSeek 官方鲸鱼 Logo。
  • 可配置：端口、默认工作区、窗口大小位置、浏览器、API 地址均可在配置文件中调整。

2. 运行原理

桌面版本身不改变 DeepSeek Harness 的架构，它做的是「首次配置 + 随窗口启停的后台服务 + 前台独立窗口」：

  1. 首次使用：检测本机是否已配置 DeepSeek API Key；未配置则弹出输入框，联网校验后保存到 ~\.dsh\.credentials.yaml。
  2. 检测后台 Web 服务是否已在运行（默认 http://127.0.0.1:3080）；未运行则执行 dsh web（等价于 npx @deepseek-ai/dsh web）并等待就绪。
  3. 服务就绪后，自动选择浏览器（默认系统默认浏览器），以「应用模式」打开独立窗口。
  4. 窗口关闭后，启动器结束由它启动的后台进程并退出；下次点击图标时自动重新启动。

3. 系统要求

项目要求
操作系统Windows 10 / 11（64 位）
Node.js已安装且 node.exe 位于系统 PATH 中（本机默认 E:\Node.js）
浏览器任意现代浏览器（Chrome / Edge / QQ浏览器 / 360 / Firefox / Brave 等）。Chromium 系浏览器可获得无地址栏的独立窗口体验
DeepSeek Harness已通过 dsh 完成初始化（存在 DSH_HOME 配置档，默认 C:\Users\<用户名>\.dsh）

4. 安装步骤

1
打开程序目录：E:\Deepseek Harness\desktop。
2
双击运行 install.cmd（或右键 install.ps1 →「使用 PowerShell 运行」）。
3
安装脚本会校验 Node.js 与 Edge，并在桌面和开始菜单各创建一个 「DeepSeek Harness」快捷方式。
4
看到「安装完成」提示即表示成功。
提示：若安装后图标未立即更新为官方 Logo，可重启资源管理器或注销重登录一次，Windows 图标缓存刷新后即会显示。

5. 使用方法

  1. 双击桌面上的 「DeepSeek Harness」图标。
  2. 首次使用会弹出窗口要求输入 DeepSeek API Key（掩码显示），联网校验通过后自动保存；之后无需再次输入。
  3. 启动器在后台启动服务，通常数秒后自动弹出应用窗口（无浏览器工具栏）。
  4. 在窗口中即可像网页版一样开始对话与使用（工作区、会话、设置等均与网页版一致）。
  5. 关闭窗口后，启动器会自动结束后台服务进程并释放窗口；下次点击图标会重新启动。
说明：后台服务仅在窗口打开期间运行，关闭窗口即停止。若使用 QQ 浏览器等无法可靠感知窗口关闭的浏览器，服务可能不会自动停止，建议在 config.json 中设置 "browser": "edge"（Edge 原生支持无边框应用窗口）以获得完整的自动启停体验。

7. 常见问题

Q1：双击图标没有反应？

请查看启动日志：%LOCALAPPDATA%\DeepSeekHarness\launcher.log。常见原因：

  • Node.js 不在 PATH 中 —— 可运行 start.cmd 查看控制台报错。
  • 未安装任何受支持的浏览器。
  • 应用已在运行（单实例保护，本次不再重复启动）。

Q2：窗口打开了，但页面一直转圈或报错？

通常是后台服务未就绪。等待数秒后刷新（窗口内 Ctrl+R）；若仍不行，查看服务日志 %LOCALAPPDATA%\DeepSeekHarness\server.log。

Q3：提示端口 3080 被占用？

说明已有一个 dsh web 服务在运行（启动器会自动复用，不会重复启动）。若占用者是其他程序，可在 config.json 中更换 port，并同步以 dsh web --port <新端口> 方式启动服务。

Q4：桌面图标显示的还是旧图标？

Windows 会缓存图标。重启资源管理器（任务管理器 → 结束「Windows 资源管理器」→ 重新运行）或注销重登录即可刷新。

Q5：想换回自定义「DS」图标？

运行程序目录下的 make-icon.ps1 可重新生成「DS」风格图标；运行 make-official-icon.ps1 可重新生成官方鲸鱼图标（需 deepseek-official.png 存在）。

Q6：想指定用某个浏览器打开？

编辑 config.json，把 browser 设为对应值即可，例如 "browser": "edge" 或 "browser": "chrome"。 默认 auto 会自动使用系统默认浏览器。Chromium 系浏览器会以独立窗口（无地址栏）打开；Firefox 会以新窗口打开。

Q7：首次使用时如何输入 / 更换 API Key？

首次使用时启动器会自动弹出输入框（掩码显示），输入后联网校验，通过即保存到 C:\Users\<用户名>\.dsh\.credentials.yaml。要更换，直接编辑该文件中的 DEEPSEEK_API_KEY 一行，或删除该行后重新点击图标（会再次弹出输入框）。

Q8：API Key 校验失败怎么办？

  • 提示“格式不正确”：Key 应以 sk- 开头，请检查是否复制完整。
  • 提示“认证失败 401”：Key 错误或已失效，请到 DeepSeek 开放平台重新生成。
  • 提示“无法连接”：网络不通或无法访问 api.deepseek.com，请检查网络/代理。

8. 卸载

  1. 双击运行程序目录下的 uninstall.cmd。
  2. 脚本会删除桌面与开始菜单中的快捷方式（程序文件保留，以便重新安装）。
  3. 如需彻底删除，手动删除整个 E:\Deepseek Harness\desktop 目录，以及日志目录 %LOCALAPPDATA%\DeepSeekHarness。
