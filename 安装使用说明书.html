1. 产品简介

DeepSeek Harness 桌面版 是一个基于 Electron 的本地桌面软件：双击桌面图标，即可在一个原生窗口中打开 DeepSeek Harness。它不依赖任何浏览器（内置 Chromium），无标签页、无地址栏，体验如同一个本地安装的独立软件。

  • 原生软件：Electron 原生窗口，与 QQ浏览器 / Edge / Chrome 完全无关，不会再出现浏览器打不开或另开窗口的问题。
  • 启动动画：启动时显示「DeepSeek Harness」动画（DeepSeek 鲸鱼图标 + 进度条），加载完成后自动进入。
  • 随窗口启停：打开软件自动启动后台 dsh web（默认 127.0.0.1:3080）；关闭窗口自动结束后台进程，3080 端口随之释放。
  • 首次配置：首次使用时弹出输入框要求输入 DeepSeek API Key 并联网校验，通过后保存到本机凭据。
  • 官方图标：桌面/开始菜单图标采用 DeepSeek 官方鲸鱼 Logo。
  • 可配置：端口、工作区、窗口大小位置、API 地址均可在配置文件中调整。

2. 运行原理

Electron 主进程负责「首次配置 + 后端启停 + 原生窗口」三件事：

  1. 首次使用：检测本机是否已配置 DeepSeek API Key；未配置则弹出输入框，联网校验后保存到 ~\.dsh\.credentials.yaml。
  2. 检测后台服务（默认 http://127.0.0.1:3080）；未监听则启动 dsh web（等价于 npx @deepseek-ai/dsh web）并等待就绪。
  3. 打开原生窗口加载该地址，关闭启动动画。
  4. 窗口关闭 → 结束由它启动的后台进程 → 软件退出；下次点击自动重启。

3. 系统要求

项目要求
操作系统Windows 10 / 11（64 位）
Node.js已安装且 node.exe 位于 PATH（本机默认 E:\Node.js）
浏览器无需任何浏览器（Electron 已内置 Chromium）
DeepSeek Harness已通过 dsh 完成初始化（存在 DSH_HOME 配置档，默认 C:\Users\<用户名>\.dsh）
DeepSeek API Key首次使用时输入并联网校验（免费申请见 DeepSeek 开放平台）
说明：Electron 运行时已打包在 app\node_modules\electron 内；从源码安装时需执行一次 npm install 下载该运行时（约 100MB）。

2

5. 使用方法

  1. 双击桌面上的 「DeepSeek Harness」图标。
  2. 首次使用会弹出窗口要求输入 DeepSeek API Key（掩码显示），联网校验通过后自动保存，之后无需再输。
  3. 显示「DeepSeek Harness」启动动画，后台自动启动服务，通常数秒后弹出原生窗口。
  4. 在窗口中即可像网页版一样开始对话与使用（工作区、会话、设置等均与网页版一致）。
  5. 关闭窗口后，软件自动结束后台服务并释放 3080 端口；下次点击图标重新启动。
说明：后台服务仅在软件打开期间运行，关闭即停。若后台服务是外部先启动的（例如用命令行手动运行了 dsh web），关闭本软件不会误杀它。

6. 配置说明

编辑程序目录下的 config.json 可自定义启动行为，保存后下次启动生效：

字段默认值说明
host127.0.0.1服务监听地址
port3080服务端口（与后台 dsh web 一致）
workspaceE:\Deepseek Harness冷启动时新会话的默认工作区目录
windowWidth1440窗口宽度（像素）
windowHeight900窗口高度（像素）
windowPositionX80窗口左上角 X 坐标
windowPositionY40窗口左上角 Y 坐标
apiBaseUrlhttps://api.deepseek.comAPI Key 校验与模型调用的 DeepSeek API 地址（可改为 OpenAI 兼容网关）
keyEnvDEEPSEEK_API_KEY凭据键名，对应 ~\.dsh\.credentials.yaml 中的条目
说明：browser / browserFamily 是旧版「浏览器启动器」的遗留字段，Electron 版忽略它们；旧版 launcher.js 仍可作为备用入口。

7. 常见问题

Q1：双击图标没有反应？

请查看日志：%LOCALAPPDATA%\DeepSeekHarness\launcher.log。常见原因：Node.js 不在 PATH、首次使用未完成 API Key 配置、或 Electron 运行时缺失（需在 app 目录执行 npm install）。

Q2：窗口打开了，但页面一直转圈或报错？

通常是后台服务未就绪。等待数秒后按 Ctrl+R 刷新；若仍不行，查看 %LOCALAPPDATA%\DeepSeekHarness\server.log。

Q3：提示端口 3080 被占用？

说明已有一个 dsh web 在运行（本软件会自动复用）。若占用者是其他程序，可在 config.json 更换 port，并以 dsh web --port <新端口> 启动。

Q4：首次使用时如何输入 / 更换 API Key？

首次使用自动弹出输入框（掩码显示），校验通过后保存到 C:\Users\<用户名>\.dsh\.credentials.yaml。更换时直接编辑该文件里的 DEEPSEEK_API_KEY 一行，或删除该行后重新点击图标。

Q5：API Key 校验失败？

  • 格式不正确：Key 应以 sk- 开头，请检查是否复制完整。
  • 认证失败 401：Key 错误或已失效，请到 DeepSeek 开放平台重新生成。
  • 无法连接：网络不通或无法访问 api.deepseek.com，请检查网络/代理。

Q6：桌面图标显示的还是旧图标？

Windows 会缓存图标。重启资源管理器（任务管理器 → 结束「Windows 资源管理器」→ 重新运行）或注销重登录即可刷新。

8. 卸载

  1. 双击运行程序目录下的 uninstall.cmd（删除桌面与开始菜单快捷方式，程序文件保留）。
  2. 如需彻底删除，手动删除整个 E:\Deepseek Harness\desktop 目录，以及日志目录 %LOCALAPPDATA%\DeepSeekHarness。
